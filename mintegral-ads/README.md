# Mintegral ad creatives – Call Blocker / Spam Filter

Static image ads for `com.blockcall.id.spam.filter.app`.

3 concepts × 7 sizes = 21 PNGs in `output/`:

| Concept | Headline | CTA |
|---|---|---|
| `shield` | Block Spam Calls | INSTALL FREE |
| `callerid` | Who's Calling? | TRY NOW |
| `scam` | Tired of Scam Calls? | GET IT FREE |

Sizes: 1200x628, 480x320, 300x250, 320x480, 720x1280, 1080x1920, 320x50.

Phone numbers shown use the fictional 555-01xx range. No ratings, install
counts or performance claims are shown.

Regenerate: `cd src && node build.js` (needs Playwright + Chromium).
Edit copy and colors in the `CONCEPTS` object in `src/build.js`.
